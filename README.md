# AI Based Flood and Landslide Prediction System for India

## Project Overview

This project uses Machine Learning techniques to predict flood and landslide risks based on environmental parameters such as rainfall, soil moisture, elevation, slope, river distance, and population density.

## Features

- Flood Risk Prediction
- Landslide Risk Prediction
- Machine Learning based Decision Support
- Streamlit Web Application
- Data Visualization and Analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Matplotlib
- Seaborn
- Folium

## Dataset Features

- Rainfall (mm)
- Temperature (°C)
- Soil Moisture
- Elevation (m)
- Slope (degrees)
- River Distance (km)
- Population Density

## Machine Learning Models

- Random Forest Classifier
- Decision Tree Classifier
